# Adrian Jay Portfolio — GHL & Creative Specialist

A Next.js portfolio starter with GoHighLevel specialization as the main focus and creative services as supporting capabilities.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Sections
- Hero / positioning
- About
- GoHighLevel expertise
- Filterable project gallery (GHL, Creative, Video, AI)
- Creative capabilities
- Tools
- Contact

## Before publishing
Replace placeholder project visuals and descriptions with actual screenshots, videos, and approved client details. Do not publish client assets or identifying information without permission. Update the contact email in `app/page.tsx`.


## Deploy
Commit to GitHub and import the repository into Vercel. Vercel will build and deploy the Next.js app. Connect a custom domain after deployment.
